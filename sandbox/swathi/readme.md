# Sandbox Environment: Swathi

Welcome to your dedicated experimental space! This folder is designed for rapid prototyping, testing, and initial data exploration.

## ⚠️ Sandbox Rules
* **No Commits to Main:** Please **do not** directly merge or push experimental code from this folder to the `main` branch. 
* **Experimental Freedom:** This is a safe space to break things. Feel free to test new libraries, optimize code, or conduct messy data extractions here.
* **The Promotion Workflow:**
    1. **Experiment:** Develop and test your logic within this sandbox.
    2. **Verify:** Ensure the code runs successfully and fulfills the intended requirement.
    3. **Branch:** Once verified, create a new feature branch from `main` (e.g., `feature/solar-ingestion-logic`).
    4. **Merge & Review:** Move the tested code to the branch and initiate a Pull Request for the team to review and merge into `main`.
