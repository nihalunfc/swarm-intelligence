# Phase 2: XGBoost Baseline Model

This directory contains the baseline predictive model for ERCOT Coast load.

## Files
- `baseline_xgboost.py`: The main training script. It loads the master 2018-2022 dataset, performs a chronological 4-year / 1-year split, engineers cyclical time features, and trains both a Linear Regression and an XGBoost Regressor for comparison.
- `predictions_vs_actuals.png`: An output visualization generated by the script showing the model tracking the actual ERCOT load over a sample week in July 2022.

## Running on Kaggle
Because the dataset size is manageable (43,822 rows), this XGBoost model trains in under 5 seconds on a standard CPU. It **does not require GPU acceleration**.

However, if you wish to run extensive hyperparameter tuning (e.g., Grid Search) which could benefit from Kaggle's infrastructure:
1. Upload the `phase_01_master_environment_full_2018_2022.csv` to Kaggle as a private Dataset.
2. Create a new Kaggle Notebook attached to that dataset.
3. Copy the contents of `baseline_xgboost.py` into the notebook cells.
4. Update the `data_path` variable to point to your Kaggle input directory (e.g., `/kaggle/input/ercot-nrel-merged/phase_01_master_environment_full_2018_2022.csv`).

## Results
The XGBoost regressor dramatically outperforms the linear baseline, proving that non-linear relationships (like extreme temperatures driving up load exponentially) are captured:

| Metric | Linear Baseline | XGBoost Regressor |
|--------|-----------------|-------------------|
| MAE    | 1488.14 MW      | **909.44 MW**     |
| RMSE   | 1983.29 MW      | **1127.47 MW**    |
| MAPE   | 10.68 %         | **6.73 %**        |

**Top 3 Features Driving ERCOT Load:**
1. `NREL_Temperature_C` (28.5% importance)
2. `Hour` (25.8% importance)
3. `Hour_sin` (18.7% importance)
